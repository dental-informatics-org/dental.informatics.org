# Dental Implant Planning Datasets

DRIVE - https://drive.google.com/drive/folders/1WfTvx-01RxnYNRiU_wjGpIzA_V1mXdcj?usp=sharing


This directory contains organized folders for different types of dental imaging data used in the coDiagnostiX tutorial.

## Folder Structure

*   **[CBCT_Implant_Planning](./CBCT_Implant_Planning/)**
    *   **Content:** 3D Cone Beam CT data (GIPL volumes included).
    *   **Usage:** Primary data source for implant planning (Module 1-3).
    *   **Status:** Sample files included.
*   **[Intraoral_Scans](./Intraoral_Scans/)**
    *   **Content:** .STL surface scan of a mandible.
    *   **Usage:** Prosthetic-driven planning and guide design (Module 4).
    *   **Status:** Sample file included.
*   **[Panoramic_Screening](./Panoramic_Screening/)**
    *   **Content:** 2D panoramic X-ray image.
    *   **Usage:** Initial case assessment and pathology screening.
    *   **Status:** Sample file included.

## How to Use
1.  **Navigate** to the specific folder for the module you are studying.
2.  **Open** the files using your dental planning software (coDiagnostiX) or a medical image viewer (like 3D Slicer).
3.  **Follow** the "Analysis Tasks" listed in each folder's README.

> **Note on File Formats:** The CBCT data provided is in `.gipl.gz` format (common in research). If your software requires `.dcm` (DICOM), you can use free tools like 3D Slicer to convert them.
