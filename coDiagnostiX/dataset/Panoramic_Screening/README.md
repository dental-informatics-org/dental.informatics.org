# Panoramic X-Rays for Screening

**Module Relevance:** Module 1 (Anatomy Review)

## Included Files
*   **`sample_panoramic.jpg`**: A sample panoramic dental radiograph showing full dentition.

> **Source:** Wikimedia Commons. [Original File](https://commons.wikimedia.org/wiki/File:Dental_x-ray_film_05.JPG). Public Domain / CC License.

## Data Description
Panoramic radiographs (OPG) provide a 2D overview of the entire jaw. While not used for 3D guide design, they are critical for:
*   Identifying gross pathology (cysts, tumors).
*   Counting teeth and identifying missing ones.
*   General assessment of bone levels.

## Analysis Tasks
1.  **Review:** Open `sample_panoramic.jpg` to identify the mental foramen location relative to premolars.
2.  **Planning:** Note which teeth are missing and require implants.
3.  **Pathology Check:** Look for any radiolucencies (dark spots) at the root tips (apices) of the teeth.
